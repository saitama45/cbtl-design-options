# CBTL rewards app: design options

Design proposal: three visual directions for the CBTL rewards app, for stakeholders to
compare.

**View it:** https://saitama45.github.io/cbtl-design-options/

This is not a live service. The prototypes are clickable mock-ups: they have no real
sign-in, and they send and save nothing. All names, stores, campaigns and codes are
sample data, and the logo is a working trace rather than official artwork.
